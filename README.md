# KI-Blueprint

*Ein gemeinsamer Ansatz für den produktiven Einsatz von KI in der Softwareentwicklung*

Der KI-Blueprint beschreibt, wie Entwicklungsteams KI-Agenten über den gesamten Entwicklungsprozess hinweg einsetzen: von der Anforderungsanalyse über die Implementierung bis zum Code Review. Er ist in der Working Group „AI-Whitepaper“ bei Atos entstanden und basiert auf den Erfahrungen aus einem internen Referenzprojekt.
